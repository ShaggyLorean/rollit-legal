Roll It — Privacy Policy

Deadsector · Last updated: 26 August 2026

Roll It is an offline puzzle game developed by Deadsector. This policy explains what data the game handles. The short version: we collect nothing.

Data collection

Roll It does not collect, store, transmit, or share any personal data. The game contains no analytics, no advertising SDKs, no account system, and makes no network requests during play.

Local data

Your game progress (completed levels, scores, settings) is saved only on your own device, in the app's private storage. It is never uploaded by the game. On Android, this file may be included in your device's standard system backup (Google's Android Backup Service), which is controlled by your device settings and Google's own privacy policy. Uninstalling the game deletes the local data.

Permissions

The game requests vibration access for optional haptic feedback. It does not request access to your contacts, location, camera, microphone, files, or identity.

Children

The game is suitable for general audiences and collects no data from any user, including children.

Changes

If a future version of the game changes any of the above (for example by adding optional online features), this policy will be updated before that version is released.
